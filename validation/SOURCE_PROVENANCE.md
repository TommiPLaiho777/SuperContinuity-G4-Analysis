# Rhino 8 alpha source and validation provenance

Alpha 0.1.0 source snapshot was tested in local Rhino 8 run `r004` on 2026-10-16. Recorded harness result: 180/180 tests passed and 19 fixture CSV exports; the build reported 0 warnings and 0 errors. This historical run limits its result to temporary reference fixtures and does not claim a full-trimmed-seam G4 certificate. It does not test the Alpha 0.1.1 coverage-honesty changes.

The G4 implementation and UI semantics in this package (`ContinuityAnalyzer.cs`, `ContinuityDefinitions.cs`, `ContinuityEvaluator.cs`, `ContinuityGrade.cs`, `ContinuityReports.cs`, `ContinuityTableForm.cs`, `SectionJetEvaluator.cs`, `SurfaceGraphJetEvaluator.cs`, and `KnotAwareSampler.cs`) match the r004 tested source files byte for byte. `KnotCoverageAudit.cs` has the same implementation; only its command name lacks the `SCAT` prefix that the isolated test harness added to avoid command collisions.

For Alpha 0.1.1, the G4 display/coverage classification, seam table, CSV columns and viewport rendering were changed after the `r004` baseline run. The standalone regression program verifies 16 constructed-report assertions, including S122-shaped partial coverage, complete coverage, an observed G4 failure, unchanged G2/G3 states, and a cap-only case with the knot audit disabled. The candidate `.rhp` is freshly built from the included 0.1.1 source against the installed Rhino 8 SDK. A new native Rhino 8 run did not complete because Rhino exited after a licensing warning; therefore the 0.1.1 binary has not yet passed a Rhino-host test. Reference formulas and baseline station results are documented in `../examples/REFERENCE_GEOMETRY.md`, `RHINO8_G4_RESULTS.md`, and `G4_REFERENCE_MEASUREMENTS.csv`. They establish outcomes for those analytic fixtures and finite sample stations only. General plugin results remain sampled and are not interval-wide certificates.
