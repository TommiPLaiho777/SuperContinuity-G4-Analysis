# Rhino 8 alpha source and validation provenance

Alpha 0.1.0 source snapshot was tested in local Rhino 8 run `r004` on 2026-10-16. Recorded harness result: 180/180 tests passed and 19 fixture CSV exports; the build reported 0 warnings and 0 errors. This historical run limits its result to temporary reference fixtures and does not claim a full-trimmed-seam G4 certificate. It does not test the Alpha 0.1.1 coverage-honesty changes.

The Alpha 0.1.0 snapshot matched the r004 production implementation. Its isolated harness used `SCAT` command prefixes to avoid collisions with installed plug-ins. Alpha 0.1.1 subsequently changes the display, coverage classification, CSV and viewport code; those changed files must not be described as byte-identical to the r004 baseline.

For Alpha 0.1.1, the G4 display/coverage classification, seam table, CSV columns and viewport rendering were changed after the `r004` baseline run. The current standalone regression program verifies 21 constructed-report assertions, including S122-shaped partial coverage, complete coverage, an observed G4 failure, unchanged G2/G3 states, and cap-only cases with auditing disabled or independently complete. The candidate `.rhp` is freshly built from the included 0.1.1 source against the installed Rhino 8 SDK. An earlier native attempt exited after a licensing warning. A subsequent native Rhino 8 run on 2026-10-16 completed with 180/180 self-tests and 19 fixture CSV exports using byte-identical production C# files from the first candidate snapshot in the isolated test harness. The later cap-only policy correction and teaching comments are not included in that native run; their new native check was safely deferred while ACC was running.
